# Spanish Possessives

Ten beginner Spanish sentences, one question at a time, with a blank possessive and clickable choices to the right. English hints identify the intended owner. Practices mi/mis, tu/tus, su/sus, and nuestro/nuestra/nuestros/nuestras.

Extra-large bold type: 44px base, approximately 64px Spanish sentences, and 48px choices on desktop. Each answer is scored immediately, with green and red answer colors and a final score. Answering fills the blank with the correct Spanish possessive and reveals an English translation beneath the sentence. Select Next to continue reading at your own pace. Restart shuffles questions and choices.

Open index.html directly; no build or account needed. Published with GitHub Pages from main. Answers stay in memory in the browser tab.
